## 1. Sommaire exécutif (1 page)

Cette formation de **1 jour** forme des adultes débutants aux bases de l'IA générative (LLM, prompting, workflow, éthique). **Aucun prérequis technique.**

### Ce que le stagiaire sait faire après 1 jour
- Structurer un prompt efficace (Rôle + Contexte + Tâche + Format).
- Générer une réponse de support client avec un LLM local (LM Studio).
- Identifier 3 cas d'usage métier et leurs limites.
- Reconnaître une hallucination et post‑traiter une sortie IA.

### Chiffres clés
| Indicateur | Valeur |
|---|---|
| Prix par stagiaire | 1 200 € HT |
| Capacité / an (An 1) | 120 stagiaires |
| CA An 1 | 144 000 € |
| Résultat net An 1 | 58 000 € |
| Point mort | 7 sessions/an |

### Prochaine étape
**Lancer la session pilote** (8-10 stagiaires) sous 30 jours, collecter le NPS, ajuster le programme, puis démarrer la commercialisation LinkedIn + partenariats PME.

## 2. Fiche de cadrage pédagogique

### Profil stagiaire
Adulte, aucun prérequis, accès Internet ou LM Studio local, objectif : comprendre et utiliser l'IA générative dans le contexte professionnel.

### 5 objectifs mesurables
1. Définir « Prompt », « LLM », « Hallucination », « Token », « Inference ».
2. Structurer un prompt avec Rôle + Contexte + Tâche + Format.
3. Réaliser un workflow : Question → LLM → Post‑traitement → Validation.
4. Identifier 3 cas d'usage métier (support, contenu, traduction) + 1 limite.
5. Reconnaître 2 limites éthiques (biais, confidentialité).

### Prérequis
Aucun.

## 3. Programme détaillé

### Module 1 — Vocabulaire IA & LLM (45 min)
- Qu'est-ce qu'un LLM, un Prompt, un Token, une Hallucination ?
- Analogie restaurant (Prompt = commande, LLM = cuisinier).
- Exemple : « Décris un chirurgien » → biais genre.
- Éval : QCM 3 questions.

### Module 2 — Outils Génératifs & Prompting (60 min)
- Structure du prompt : Rôle + Contexte + Tâche + Format.
- Exemple : prompt support client, prompt marketing, prompt traduction.
- Éval : transformer un prompt vague en prompt structuré.

### Module 3 — Cas d'Usage Métier & Workflow (60 min)
- 3 cas : support client, contenu, traduction.
- Workflow : Donnée → LLM → Post‑traitement → Validation.
- Exemple : e‑commerce (produit endommagé → réponse → validation).
- Éval : compléter le tableau cas d'usage / outil / entrée / sortie.

### Module 4 — Éthique, Limites & Tendances (45 min)
- Biais, confidentialité, hallucinations, multi‑modalité, agents.
- Exemple : ne jamais envoyer de données sensibles à un LLM public.
- Éval : Vrai/Faux 4 questions.

### Synthèse & Certification (15 min)
- Quiz final (10 questions, seuil 7/10), badge, plan de suivi.

## 4. Kit atelier pratique (2h)

### Scénario
Créer un assistant de support client avec un LLM.

### 3 Défis incrémentaux
1. Premier prompt (10 min) → réponse polie 3 phrases.
2. Prompt structuré (20 min) → ton empathique, 4 phrases.
3. Workflow complet (30 min) → 3 questions traitées, 1 validation.

### Matériel
PC, LM Studio ou Ollama, modèle `qwen3.8:27b`, navigateur, ce kit.

### Grille d'auto‑évaluation (5 items)
1. Structurer un prompt. 2. Générer une réponse. 3. Identifier une hallucination.
4. Post‑traiter. 5. Reconnaître une limite éthique.
